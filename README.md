# 燈帶造型工作室 1.0
2026-11-09

使用方式：解壓縮後，雙擊「燈帶造型工作室-直接開啟.html」，使用支援WebGL的Chrome或Edge。此為免安裝網頁工具，不是Windows EXE。無需網路載入素材。

功能：直線、波浪、圓環、愛心、文字燈牌、自訂節點曲線。最多30圖層，支援選取、複製與移除，獨立色彩、亮度、粗細、尺寸、位置、角度及開關。文字以發光平面呈現，並非文字的實際彎管路徑；粗細控制適用曲線造型。
自由畫線時會切到正面，點兩個以上節點後按完成；可取消。預覽模式拖曳旋轉、滾輪縮放，亦有正面／立體與加減按鈕。
按「儲存設計」才保存至目前瀏覽器；下載JSON可備份及移機。瀏覽器清除資料或移動HTML可能改變存取位置，重要作品請下載備份。PNG只匯出3D預覽、不含選取框及介面。

驗證：程式語法及設計資料格式、上下限、無效數值、節點及深層複製檢查通過；瀏覽器實測新增圓環及文字、三節點畫線、複製／移除、保存後重新整理恢復。手機多指、PNG和JSON實際下載／重新匯入尚未端到端驗證。
